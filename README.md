## [Dynamic Cube](https://wee-owl.github.io/dynamic-cube/)
Тестовое задание, включающее в себя работу с библиотекой Three.js для 3D-моделирования.

### Цель
Реализовать интерфейс максимально идентичный представленному на главной странице. Используются функциональные компоненты. В devtools не должны присутствовать критические ошибки.

## Технологии
- React
- TypeScript
- React Router
- Redux Toolkit
- Three.js

## Функциональность
Основная страница:
- Размер элемента-контейнера с кубиком - резиновый.
- Внешние отступы элемента-контейнера левый/правый - 15%.
- Соотношение ширины/высоты - 3/2. Соотношение сохраняется при изменении ширины элемента.
- Фоновую картинку скопировать из интерфейса. Затемнение фоновой картинки - rgba(0, 0, 0, 0.4).
- Все стили берутся из представленного интерфейса (в devtools).
- Кубик должен крутится.
- Должна быть реализована возможность покрутить кубик мышкой.
- Стороны кубика закрашиваются через background, не картинкой.
- На каждой стороне кубика должена присутствовать текстовая надпись с названием стороны. Текст, не картинка.
- Должен быть реализован переход на страницу стороны кубика.
- Переход осуществляется по двойному клику.

Страница стороны кубика:
- Должен быть тот же заголовок, что и на основной странице.
- Должен быть тот же элемент-контейнер, что и на основной странице.
- Должна присутствовать кнопка возврата на основную страницу.
- Url страницы стороны должен включать id.
- Информация в контейнере: id, левый отступ клика от родителя в пикселях, верхний отступ клика от родителя в пикселях, uuid стороны, текст стороны.
- На странице стороны должен быть кружочек в том месте, где был клик на основной (смотрите пример интерфейса).
